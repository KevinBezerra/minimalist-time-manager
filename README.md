# Minimalist Time Manager

A simple, lightweight application designed to help people manage their time with the minimum amount of time invested in time management.

## Features

- **Quick Task Creation:** Fast text input feature to add new tasks on the fly.
- **Task List:** Clear, distraction-free view of all tasks.
- **Daily Schedule:** Straightforward planning view to map tasks across the day.

## Tech Stack

- **Frontend:** React
- **Backend:** Node.js / Express
- **Storage:** SQLite (or browser LocalStorage)
